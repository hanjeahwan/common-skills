# AGENTS.md

All skill creation or maintenance in this repository MUST go through `dao-skill`:

1. Load it (resolve via `~/.agents/skills/dao-skill/SKILL.md` or installed skill search).
2. Follow its instructions. They own the workflow, checks, and gates — do not duplicate or override them here.
3. Do not create or edit a `SKILL.md` outside that workflow.

Layout: skills live in `.agents/skills/<name>/` (`SKILL.md`, `tests/cases.md`, `references/`), listed in `README.md`.
