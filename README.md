# Goal Loop

Goal Loop is a agent skill for pursuing bounded goals through repeated observation, decision, action, and verification. It keeps the L0 Objective immutable, L1 Acceptance Criteria protected, and the L2 Approach adaptive, while persisting the goal and compressed checkpoint under `.goal/` so work can resume across context resets and stop only at `BLOCKED` or `DONE`.

See [the skill](.agents/skills/goal-loop/SKILL.md).
